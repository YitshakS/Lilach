# Lilach – יוזמה לבנות דתיות ציוניות ב-8200

מצגת בת שישה עמודים (HTML סטטי), לפגישה עם עוזרת שר הביטחון.

## הפעלה

פותחים את `index.html` בדפדפן (או `python -m http.server` בתיקייה ואז `http://localhost:8000`).
הפונטים נטענים מ-Google Fonts, ולכן נדרש חיבור לאינטרנט.

## ניווט

| פעולה | מקש / מחוות |
|---|---|
| הבא | חץ שמאלה, רווח, Enter, PageDown, או כפתור שמאלי על המסך |
| קודם | חץ ימינה, Backspace, PageUp, או כפתור ימני על המסך |
| ראשון / אחרון | Home / End |
| מסך מלא | `F` |
| מובייל | החלקה ימינה = הבא (RTL) |

פס הניווט (נקודות ומונה) מופיע בתנועה ונעלם אחרי כמה שניות.

## עמודים

1. `index.html` – פתיחה
2. `hesder.html` – מסלול הסדר
3. `hadasim.html` – תוכנית הדסים
4. `kodkod.html` – תוכנית קודקוד
5. `petition.html` – דף העצומה
6. `replies.html` – תגובות של בנות שביקשו להתגייס (שמות, טלפונים, דוא"ל ושנות לידה מטושטשים)

הניווט נמצא ב-`nav.js` וב-`nav.css`, והתמונות ב-`assets/`.

## פרטיות

הטבלה בעמוד 6 מטושטשת בתמונה עצמה. קובץ המקור הלא מטושטש לא נמצא בריפו.
